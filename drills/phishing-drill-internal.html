一、方案总览

项内容
目标建立可持续的钓鱼演练能力：季度一轮、全员工覆盖、点击率年目标 30%→10% 以下、上报率 >50%
范围全员邮箱（首轮）；后续轮次加码高风险部门（财务/采购/HR/高管）
技术栈演练平台（Gophish）+ 域名/发信基础设施 + 教育落地页 + Splunk 记账 + 企微通知
红线不收集真实密码（落地页只记录"提交"动作）；不与绩效挂钩；数据仅安全团队可见
第 1-2 周：基础设施搭建（工具选型落地、域名与发信配置）
第 3 周：模板制作与内部试测（先打 IT 自己）
第 4 周：首轮全员演练 + 即时教育
第 5 周：数据复盘、网关规则同步、报告输出
每季度：循环一轮，难度递增（详见 ④）

二、工具选型

方案成本优点缺点结论
Gophish（开源） 0（自建） 开源事实标准；模板/活动/统计全功能；数据完全自持（不出公司）；Docker 一键部署 需要自备发信域名和 SMTP；报表需二次加工 推荐首选
商业 SaaS（Proofpoint/KnowBe4/GoPhish 云版） ¥100-300/人/年 模板库丰富、自动难度递增、合规报表现成 员工行为数据出境到第三方；续费成本；定制弱 预算充足且人数多时再评估
自写脚本 0 完全可控 追踪打开/点击/提交的全链路埋点工作量巨大，不值得重造轮子 否

2.1 Gophish 部署要点（Docker）

# 数据已有 Docker 环境（asset-monitor 同机或独立）
docker run -d --name gophish \
  -p 3333:3333 \    # 管理界面
  -p 8080:80 \      # 落地页/追踪
  -v /data/gophish:/opt/gophish \
  gophish/gophish

# 初始密码看容器日志：docker logs gophish | grep password
# 首登后立即改密 + 管理界面加 IP 白名单（只允许IT网段）

2.2 发信基础设施（关键，决定进收件箱还是垃圾箱）

  • 专用域名：注册一个与公司域相近的演练域（如 poppu1a-sec-test.com——形近但明确是测试）。绝不用公司正式域发钓鱼邮件（会污染正式域信誉、误伤真实邮件）
  • DNS 三件套：SPF（v=spf1 指向发信IP）、DKIM（2048 位密钥签名）、DMARC（p=none + rua 报告收件箱，先观察后收紧）
  • 预热：正式演练前 2 周开始小流量发信（每天几十封正常内容），养域名信誉，否则全进垃圾箱导致演练数据失真
  • 落地页域名：同样用演练域，配 Let's Encrypt 证书（Let's Encrypt 免费且被信任，真实攻击者也这么干——这正是演练要教的点）

三、邮件模板库（基于 2026 真实威胁设计）

模板设计原则：每一套都对应一类真实在打的攻击（数据来源：CrowdStrike GTR 2026 / DBIR 2026），并在复盘时告知员工"这不是编的，今年真有公司这么被打了"。

模板诱饵设计对应真实威胁难度目标部门
T1 假验证码页面"请完成人机验证以查看共享文档"→ 落地页模拟 CAPTCHA，实际收集凭据CrowdStrike：假 CAPTCHA 诱饵 +563%，年度增长最快低全员
T2 密码过期通知"您的邮箱密码将于24小时后过期"→ 仿 SSO 登录页凭据钓鱼常青款（DBIR：凭据滥用居前列）低全员
T3 虚假发票/对账"10月采购对账单见附件"→ 附件为 HTML 凭据页或宏文档财务供应链诈骗（BEC）主力载体中财务/采购
T4 高管冒充转账仿 CEO/总经办邮箱发"紧急付款，我先上会"（纯文本无链接，测的是流程敬畏而不是识别能力）BEC——单笔损失最高的钓鱼类型（FBI IC3 年度损失数十亿美元级）高财务/高管助理
T5 IT 部门冒充"安全团队检测到异常登录，请验证身份"（ irony：我们用假的"安全通知"教大家识别假安全通知）语音钓鱼 vishing 的邮件版；利用对 IT 的天然信任高全员（第2轮+）

3.1 落地页与凭据处理（红线）

安全红线：落地页表单不存密码——前端收到提交事件即记录"该用户已提交凭据"，密码字段直接丢弃不发送。这是演练与真攻击的本质区别，也是对员工的承诺：演练不留任何人的密码。落地页底部保留小字免责："这是 poppula 安全团队组织的演练，您的密码未被记录"（提交后才显示，不打草惊蛇）。

四、执行手册（每轮 SOP）

#步骤操作细节责任人
1授权确认邮件授权（IT负责人书面批准本轮时间/范围），抄送 IT 总监——防止演练当日被当成真实事件应急安全
2提前报备关键岗告知服务台/网管"今日有演练"，收到问询统一话术："请仔细看发件人域名"安全
3投放周二或周四 10:00 或 15:00（工作饱和时段，数据最真实）；Gophish 分批发送（避开网关速率限制）安全
4监控窗口72 小时内跟踪打开/点击/提交曲线；发现异常恐慌（大量问询）可提前中止安全
5即时教育点击者看到教育页（拆解刚才的诱饵+三个识别点）；提交者额外弹"你的密码本可以被盗——但这是演练"平台自动
6上报通道邮件页显著位置放"一键上报"按钮（Outlook 报告插件/转发安全邮箱）；上报的人无论点没点都计入正向分全员
7收尾通知72 小时后全员发"演练结束"通报：本轮点击率、最逼真的一封、表扬上报员工（匿名/数量）安全

4.1 难度递增路线（季度轮次）

轮次模板策略
Q1 首轮T1 + T2（低难度明显破绽）建基线；让"演练"概念全员知晓
Q2T3 + 定向 T4加入部门定向；引入"无链接纯社工"型
Q3T5 + 混合（同一活动两封连环）测"第一封建立信任+第二封收割"的链式攻击
Q4自定义（针对本年度真实收到的攻击仿制）用自家邮件网关拦下的真实样本做教材——最有说服力

五、度量体系（KPI 定义先于执行）

指标定义（分子/分母）行业基准我们的目标
打开率触发追踪像素 / 发送数30-40%参考值（不做考核）
点击率点击链接 / 发送数首轮 ~30%，成熟 <10%年内 30%→10%
提交率提交凭据 / 发送数首轮 ~10%<3%
上报率通过任意通道上报 / 发送数成熟 >50%逐轮上升（最优先指标）
上报时延首封上报时间 - 发送时间小时级→分钟级中位数 <30 分钟
复发率上轮点击本轮再点 / 上轮点击数—<20%（教育有效性验证）
上报率为什么最优先：点击率有下限（再训练也会有人手滑），但上报率没有上限——每多一个上报的员工，等于多了一个免费传感器。对照攻击者 29 分钟的横向移动窗口：50 个员工的分钟级上报网络，比任何单点技术检测都覆盖面广。

六、演练 × 邮件网关联动（每次演练都变成一次防御升级）

演练的复盘产出直接回流到网关配置——这是"演练→防御"的闭环：

演练发现网关动作
某模板点击率异常高提取模板特征（发件域/正文关键词/链接结构）→ 加为网关拦截规则
落地页被大量访问URL 分类加入网关黑名单（防真实攻击者复用同类页面）
附件被下载评估附件类型是否应默认隔离（对齐 CrowdStrike 建议：可执行附件零信任）
上报的内容被上报样本自动进安全团队审查队列（演练期与真实期同一通道，练的就是这个肌肉）

七、Splunk 集成（对齐现有 SOC）

演练事件进 Splunk 统一分析——与现有安全日志同平台，真实攻击来临时演练数据就是行为基线：

# Gophish 侧：开启 webhook，事件推送到接收端
# 接收端将事件转 syslog/HTTP Event Collector 到 Splunk：

# HEC token 方式（推荐）
curl -k https://splunk.poppula.com:8088/services/collector/event \
  -H "Authorization: Splunk " \
  -d '{"sourcetype":"gophish:campaign","event":{
    "campaign":"2026Q1-T2-password-expiry",
    "action":"clicked",           # sent/opened/clicked/submitted/reported
    "email":"user@poppula.com",
    "template":"T2",
    "ts":"..."
  }}'
  • sourcetype 规范：gophish:campaign，字段 action/email/campaign/template——直接可做 CIM 映射（对齐我们 SOC 的标准化方向）
  • 看板：按部门/模板/动作的时间序列；与邮件网关真实拦截量叠加对比（演练命中率 vs 真实攻击拦截率的关联视图）
  • 后续 LLM 研判挂钩：演练事件流与真实上报共用一条管道——LLM 研判真实邮件时，可以引用"该用户历史演练行为"做加权（高复发用户的上报误判率更高，需要更仔细研判）

八、风险控制与常见坑

风险控制措施
演练被当成真实事件引发业务恐慌① 书面授权+关键岗提前报备 ② 发送时间避开月初月末财务高峰 ③ 中止预案（发出"停止演练"全员通知的预置模板）
员工信任受损（"IT 钓我们"的抵触）① 不与绩效挂钩、不点名（管理层版已声明）② 演练通报只讲统计不讲个人 ③ 教育页语气是"教你赢"不是"抓到你" ④ 明确承诺不存密码
演练邮件外泄被截图发到外网/客户模板落地页明确标注公司名与免责（查看源码可见但不显眼）；不做丑化公司或高管的诱饵内容
域名信誉反噬演练域与正式域完全隔离；DMARC rua 监控；演练域 SPF 明确限定发信源
合规/隐私（员工行为数据）数据最小化（只记动作不存密码）；访问权限仅安全团队；保留期 12 个月后匿名化；演练前在 IT 制度中备案
